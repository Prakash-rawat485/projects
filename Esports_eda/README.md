# 📖 Overview

This repository presents a comprehensive **Exploratory Data Analysis (EDA)** of the **Esports World Cup (EWC) 2025 Medalists Dataset** using Python.

The objective is to clean, explore, visualize, and interpret esports medal data to identify meaningful trends among players, countries, games, organizations, and medal distributions.

The project demonstrates practical data analysis techniques using **Pandas, NumPy, Matplotlib, and Seaborn**, making it suitable for beginners and intermediate data analysts.

---

# 🎯 Objectives

- Clean and preprocess the dataset
- Perform descriptive statistical analysis
- Analyze medal distribution
- Identify top-performing countries
- Explore the most successful esports titles
- Analyze leading esports organizations
- Compare player and coach participation
- Generate meaningful visual insights
